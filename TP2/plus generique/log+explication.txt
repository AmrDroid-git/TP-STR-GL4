$ ./main.exe | grep "segment AB"
MR1-1 attend le segment AB     <- MR1-1 demande AB
MR1-1 occupe le segment AB     <- AB est libre, MR1-1 entre
MR1-2 attend le segment AB     <- MR1-2 veut AB mais MR1-1 est dedans : il ATTEND
MR1-1 libere le segment AB     <- MR1-1 sort, AB est de nouveau libre
MR1-2 occupe le segment AB     <- MR1-2 peut enfin entrer
MR2-1 attend le segment AB     <- MR2-1 arrive, MR1-2 est dedans : il ATTEND
MR1-2 libere le segment AB     <- MR1-2 sort
MR2-2 attend le segment AB     <- MR2-2 demande AB (AB est libre a cet instant)
MR2-2 occupe le segment AB     <- MR2-2 entre
MR2-2 libere le segment AB     <- MR2-2 sort
MR2-1 occupe le segment AB     <- MR2-1 entre enfin
MR2-1 libere le segment AB     <- MR2-1 sort
